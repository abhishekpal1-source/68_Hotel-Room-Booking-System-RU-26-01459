Hotel Room Booking System

PS No.: 68

A Python-based console application for managing hotel room bookings.

Features

- View Available Rooms
- Book and Cancel Rooms
- Generate Bills with 12% GST
- Prevent Double Booking
- Save Records in "bookings.txt"

Technologies Used

Python 3, Lists, Dictionaries, Functions, File Handling.

Run Project

python hotel_booking.py

Developed as a B.Tech CSE Academic Project.
